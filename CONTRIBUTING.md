# Contributing to VoiceForge

Open an issue with your Windows version, the affected recording, playback, or export action, and steps to reproduce the problem. Use the built-in synthetic sound demo when it reproduces the issue.

For a pull request, follow the [development notes](docs/DEVELOPMENT.md). Run `npm test` and `npm run build`, then describe what you verified. Run the desktop integration tests for changes to recording, playback, or native export.
